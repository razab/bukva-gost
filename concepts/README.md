# Лист А — версия 3

Открыть index.html. Пять оформлений используют общие ячейки письма. Под каждой ячейкой находится процент геометрического сходства и собственный сброс ↺. Процент и кнопка не лежат в canvas. Общий сброс выполняется без подтверждения; отмена восстанавливает весь снимок данных, включая сброшенную пробу или лист. Рисунок арбуза имеет отдельную поверхность и сброс.

Иллюстрация assets/watermelon-reference.png создана ImageGen для проекта и просмотрена отдельно. Страница и изображение работают локально без сети. Для переноса нужно сохранять папку concepts вместе с assets.

Данные v3 используют новый ключ хранения. Старые данные не удалялись; previous-v1.html открывает предыдущую компоновку со старыми ключами.

Проверка логики: node tests/worksheet.test.cjs. Тест запускает код настоящей страницы в моделируемом DOM: ввод, проценты, сбросы, отмена, повторное открытие, переключения, отменённый контакт. Браузерная компоновка, производительность и Pencil на реальном iPad не подтверждены этими тестами.

На листе есть пара А а: верхние образцы показывают оба регистра, после разминки идут строка А и строка а. У строчной собственные геометрия, оценка и сохранение. Округлая форма сверена с чертежом 8 ГОСТ 2.304-81; учебное движение задано для прототипа отдельно. Предыдущая компоновка с двумя заглавными строками сохранена в previous-uppercase-v3.html.

Текущий шрифт — прямой GOST type B Regular (ASCON, font-4.ttf). Раскрытие контура исправлено: маска остаётся в координатах листа на каждом кадре. Реальную SVG-отрисовку проверяет tests/reveal-render.test.cjs с установленным @resvg/resvg-js (путь можно передать через RESVG_MODULE). Предыдущий наклонный вариант сохранён в previous-inclined-font.html.

В панели «Настройки» доступны размер букв, визуальная толщина (bold) и допуск отклонения. Настройки сохраняются отдельно от рисунков. «По умолчанию» возвращает параметры, сохраняя рисунки. При изменении размера прежние линии масштабируются вместе с образцом.

«Состав страницы» открывает визуальный каталог 40 рисунков и выбор пяти частей текущих букв А/а (две наклонные, горизонталь, корпус а и её стойка с выходом вправо). Для каждого включённого типа доступны 3, 4 или 5 проб. Выбор и скрытые пробы сохраняются. Компоненты находятся в components/; при переносе страницы эта папка обязательна. Контракты для будущего редактора описаны в ../docs/page-components.md. В каждом из 40 рисунков не менее 70% контура оставлено для дорисовки; готовая часть — одна связная группа целых штрихов; проверки учитывают наложения и гарантируют минимум 70% уникального контура. Коллаж всех рисунков — assets/picture-catalog-preview.png; части букв — assets/letter-parts-preview.png. Старые записи не накладываются на новые формы упражнений.

После одиночных букв по умолчанию добавлены три пробы «ААА» — каждая в одном общем поле. В «Составе страницы → После отдельных букв» можно добавить до 12 строк с собственным текстом, выбрать 1–5 повторов каждой, отключать и удалять строки. Пока поддерживаются А, а и пробел; латинские A/a приводятся к кириллице. За него отвечает components/letter-sequence.js; сейчас используются только подготовленные буквы А/а.

В настройках также доступны вертикальный интервал между рядами (0–80 px) и горизонтальный между пробами (0–60 px). Они сохраняются и не меняют размер букв или шаг букв внутри последовательности.
