# Чертёжные буквы — правила проекта

- Учебный предмет — русский чертёжный шрифт ГОСТ 2.304-81. Не заменять его книжным печатным, школьным рукописным или декоративным шрифтом. Одноэтажная строчная а здесь ожидаема; двухэтажная книжная а не является заменой.
- Текущий вариант — тип Б без наклона (новое указание пользователя от 29.10.2026), таблица 2 и чертёж 8. Параметры и построение должны быть явными. SVG-геометрия образца, анимации, подсказок и проверочной траектории должна иметь один источник.
- Перед расширением набора сравнивать каждую форму с таблицей стандарта. Проверки высоты/ширины/наклона сами по себе не подтверждают весь контур. Не объявлять авторскую аппроксимацию сертифицированным шрифтом.
- Различать нормативную форму буквы и учебный порядок движения: ГОСТ не подтверждает сам по себе педагогический порядок штрихов.
- При изменении формы не накладывать прежние записи на новую геометрию и не удалять их молча. Использовать версию ID/архив прежней страницы.
- Общие сценарии: node concepts/tests/worksheet.test.cjs. Они моделируют DOM, не заменяют проверку браузерной раскладки и Apple Pencil. Отдельно проверять фактическую геометрию и последовательность показа А → 500 мс → а.
- После ссылки пользователя на iSopromat видимые контуры А/а берутся из исследованного готового TTF (references/isopromat-fonts/SOURCE.json), а не восстанавливаются вручную по сетке. Для следующих букв сначала проверять готовый cmap/контур. Траектория движения и оценка — отдельный слой; не подменять ей контур шрифта. До распространения проверить лицензию: бесплатная загрузка и fsType=0 не подтверждают право включения в App Store.

- Маска раскрытия применяется к внешней группе в координатах листа; преобразование контура шрифта находится внутри группы. Не снимать маску в последнем кадре ради полной заливки. Проверять растеризованные промежуточные кадры (concepts/tests/reveal-render.test.cjs), а не только изменение dashoffset.
- Размер упражнения должен использовать один масштаб для букв, чёрточек, подсказок и введённых линий. Перенос строки не должен вводить отдельный коэффициент масштаба. Проверять допуск по фактической ширине canvas в CSS-пикселях на уже сохранённой пробе; фиксированный mock 150px недостаточен.
- Оценка элементов, отдельных букв и последовательностей — единая геометрическая. Не проверять порядок, направление, число движений и отрывы пера; не добавлять специальные правила для конкретных букв/текстов и скрытый штраф 59%. Учебная последовательность нужна демонстрации. Bold должен затрагивать и глифы, и элементы.
- Поле ввода строить по границам геометрии с запасом под толщину/допуск и минимальным размером для касания. Сокращать viewport, сохраняя масштаб и исходные координаты черновиков. Одинаковые буквы в одиночной пробе и тексте должны иметь одинаковый масштаб. Допуск переводить по ширине viewport, а не прежней системы хранения 150 × 180.
- Рисунки и тренировочные элементы — компоненты из concepts/components/. Состав страницы хранить данными по известным ID; не возвращать жёсткую привязку рисунка к оформлению. Изменение числа проб или выбор компонента не должны удалять скрытые черновики. При переносе приложения включать components/ вместе с assets/.
- В рисунке для дорисовки не менее 70% длины контуров должно оставаться ребёнку. Учитывать геометрические наложения; цветная заливка не должна заранее раскрывать незавершённые части. Проверять весь каталог растеризацией и измерением геометрии.
- Разминка — части конкретных букв текущей страницы из их шрифтовых учебных траекторий. В редакторе можно исключать такие части, но нельзя предлагать посторонние примитивы. Для А: две наклонные и горизонталь. Для а: корпус с прямыми сторонами и верхним правым углом, стойка с выходом вправо; обычный овал не является заменой. Родство частей других букв проверять по выбранному TTF, не по названию элемента.

- Межбуквенный просвет по умолчанию — 0,2h (2d для типа Б) для обоих регистров; h — номинальная высота заглавной. Автоматические метрики TTF не должны подменять этот дефолт. Явные пользовательские настройки сохранять.

- Числовые ползунки должны оставаться монотонными: не помещать «авто», «из шрифта» или «дефолт» вместо крайнего числа. Значение по умолчанию отмечать отдельно на шкале; для межбуквенного интервала слева 0%, отметка дефолта — 20%.

- В рисунках для дорисовки готовая часть — одна связная группа целых линий/дуг. Не заполнять фиксированный процент каждого штриха: нельзя разбрасывать по рисунку начальные кусочки, которые ребёнку приходится обходить. Разделять на готовые и незавершённые только целые осмысленные штрихи, сохраняя минимум 70% дорисовки.

- Для выбранного шрифта без наклона разлиновка горизонтальная, без косых направляющих. Её уровни берутся из номинальных высот ГОСТ; линии проходят через промежутки между полями и учитывают реальные переносы, не меняя размеры canvas, координаты черновиков и оценку.

- Порядок уроков взят из предоставленной пользователем «Прописи. 1 класс» (Тохтаходжаева/Белова/Вейцман, Ташкент, 2019): А О И У Ы Н Т К С Л П Р В Е М З Д Б Г Ь Я Ч Ш Ж Ё Й Х Ю Ф Ц Э Щ Ъ. Полный ряд и начала групп подтверждены в references/propisi-2019-order.json. До 03.11.2026 после начальных уроков проверялись только заголовки; это не было разбором содержания. По уточнению пользователя все 72 полные страницы пересмотрены: компактный источник для следующих работ — references/propisi-2019-content.json, наглядный справочник — output/pdf/propisi-2019-content-reference.pdf, отдельные изображения — references/propisi-2019-content/pages/. Не перечитывать весь 29-МБ PDF ради уже описанных заданий; при необходимости открыть только нужное сохранённое изображение. Не приписывать источнику авторские задания. Прежний молдавский порядок заменён по указанию пользователя.
- Полный разбор выявил 33 разные по структуре буквенные группы: 9 одностраничных, 18 двухстраничных, 6 трёхстраничных. Т — 14-16, К — 17-18, С — 19-20. Урок не сводится к первой странице новой буквы: дальше есть списывание текстов, пропуски, изменение слов, сборка предложения и ответы. Не превращать короткий основной сеанс сборки 27 (14-16 полей) в универсальный предел содержания всех букв. Сохранять одну страницу приложения на букву и адаптировать её блоки/занятия к росту письменных действий. Педагогические выводы и предложения по адаптации отделять от описания источника.
- Состав урока: части строчной → строчная → сочетания/слова → части заглавной → заглавная → имена/предложения → повторение. Части — из нашего выбранного ГОСТ, без школьных связок и требования неотрывного письма. Письменный текст использует текущую и ранее введённые буквы; наличие глифа не означает, что он уже изучен. Повтор «ААА» не выдавать за слово.
- При обновлении курса автоматически заменять только точно распознанные прежние стандартные задания; исходный состав архивировать. Пользовательские строки сохранять, текст с будущими буквами оставлять в редакторе с пояснением. Не удалять записи упражнений и не менять geometry revision ради перестановки уроков. Проверки миграции/33×5 этапов: concepts/tests/propisi-flow.test.cjs.


- Полный набор хранится в concepts/components/glyphs.js и генерируется scripts/prepare-glyphs.py. Перед выпуском обновлённых маршрутов проверять все 33 пары и растровые фазы всех глифов (tests/alphabet.test.cjs с RESVG_MODULE). Не обнулять версию геометрии вручную: слова содержат буквы предыдущих уроков, поэтому версия охватывает весь реестр. А/а сохраняют одобренные маршруты и старые ключи.
- LAN-превью: PROJECT.md и start-wifi.command. Перед стартом проверить Local Projects Dashboard и уже работающий native Terminal. Сервер отдаёт только concepts/, не расширять web-root до исследовательских материалов.

- Не превращать микросоединители скелета шрифта в самостоятельные упражнения: делить маршрут только на существенные стороны. При объединении частей версионировать ID и сохранять выбор/исключения/старые черновики. Проверка всех букв должна исключать микрофрагменты, кроме настоящих точек.
- Проверять реальный браузер на крайних настройках размера/bold/допуска/интервалов: один длинный текст не должен расширять весь лист. Сохранять единый масштаб, переносить слова целиком, а слишком длинное слово — между буквами, с отдельным ID переносов.

- Лист для планшета использует доступную ширину с небольшим защитным полем/safe-area, без карточного max-width1000px. Не добавлять дублирующий заголовок буквы и строки служебных меню перед упражнениями; настройки открываются отдельно. Проверять не только отсутствие overflow, но и фактические боковые отступы в обеих ориентациях.
- Размер/bold/допуск/интервалы и режим ввода общие для уроков; состав текущей страницы отдельный. По умолчанию canvas не принимает touch; перо имеет приоритет перед незавершённым touch в разрешённом режиме. Не называть фильтр pointerType полноценным аппаратным распознаванием ладони. Проверки: concepts/tests/tablet-workspace.test.cjs.

- Геометрический скелет не доказывает осмысленный порядок начала письма. При жалобе на движение проверять первый штрих и стыки визуально, а не только итоговое покрытие. Для педагогического показa допускается glyph.demonstration с тем же исходным outline; не менять model/revision и хранилище ради одного порядка анимации. Проверять custom demonstration растеризацией на обеих толщинах, включая начало и последний кадр.
- После замечаний об О/К от 03.11.2026 источники учебного порядка собраны в references/stroke-order/index.json, наглядный атлас — output/pdf/gost-stroke-order-atlas.pdf. База: Ленский технологический техникум, стр. 36, рис. 5-6; ОГУ, Капица/Саблина, 2013, стр. 7-8. В рисунках наклонный шрифт: перенос движений на наш прямой и схемы по аналогии должны быть явно помечены, а не выданы за прямое предписание ГОСТ. 44 формы имеют отдельный образец, 19 сопоставлены с заглавными, ещё 3 получены добавлением/снятием надстрочных знаков. Автоматически извлечённый скелет и тест покрытия не подтверждают педагогический порядок. В сборке 29 О/о — две нисходящие половины, К/к — стойка, верхняя ветвь целиком до стойки, нижняя ветвь от развилки. Ранее одобренный пользователем непрерывный А сохранён как явная альтернатива учебной схеме. Проверка: tests/stroke-order.test.cjs; все контуры/model/revision и записи прежние.

- Рисунок для дорисовки по умолчанию должен соответствовать штрихам текущей буквы; не назначать одну картинку всем страницам по индексу оформления. Связи и обоснование: concepts/components/lesson-pictures.js. Сохранять явный ручной выбор отдельно от автоматического подбора, не удаляя черновики прежних рисунков.

Для выпуска предпочтительно отдельное локальное средство/сборка редактора; разработческий аккаунт не считать уже выбранным решением. Доступные родителю настройки должны решать понятную бытовую задачу, а не редактировать геометрию ГОСТ. Навигацию по урокам и прогресс не прятать в разработческие настройки.

Один viewport meta недостаточен для Safari: отдельно проверять отмену gesture/multitouch и глобальный user-select. Не выдавать mock-проверки за проверку физического iPad.
