# Учебный показ и сохранение

Пользовательский лист использует точные контуры выбранного ASCON GOST type B upright. Исходный `model` отвечает за геометрическое сравнение. Необязательный `demonstration` меняет только движение карандаша и раскрытие этого же контура. Порядок движений — авторское учебное решение, не предписание ГОСТ.

## Короткая основная практика — сборка 27

По умолчанию на странице 14–16 основных полей. Для каждого регистра выбирается один наиболее протяжённый доступный элемент из собственных частей буквы, с тремя пробами; далее три целых буквы. В строчной практике при наличии слов сочетание заменено отдельными словами, одно из которых входит в основную часть. Завершает основную часть короткая фраза, а для первых букв — сочетание с заглавной. Первые ААА/ЫЫЫ остаются по два раза. Весь материал использует уже введённые буквы.

Остальные элементы, второе слово, имена и повторение находятся под «Ещё упражнения». Открытость блока сохраняется при перестройке текущей вкладки, после перезагрузки блок снова закрыт. Счётчик показывает основную часть и отдельно число заполненных дополнительных проб; дополнительная работа продолжает сохраняться и учитываться после сворачивания. Скрытый canvas оценивается по заданному физическому масштабу, а не по нулевой ширине. Ширина дополнительных текстов берётся от всего листа, поэтому начальное свёрнутое состояние не ломает переносы.

Ручные текстовые строки автора сохраняются и остаются в основной части. Исключения элементов и настройки числа повторов также сохраняются. Автоматически заменяется только точно распознанный старый стандартный набор строк с textRowsCustomized=false; исходный состав сохраняется под ключом с суффиксом -before-short-practice-v2. Чернила, ключи полей, контуры и версия геометрии не меняются. Новая попытка и правило трёх зелёных проб в этой сборке ещё не реализованы.

## Попытки и сравнение

`gost-learning-progress-v1` продолжает хранить факт завершённого занятия: до 60 сессий на букву. Повторное завершение неизменённой работы не добавляет сессию. Незаконченные поля не блокируют завершение. Заполненные самостоятельные пробы учитываются и после их скрытия.

`gost-practice-attempts-v1` хранит отдельные попытки: до пяти последних уникальных рисунков и лучший результат каждого задания. Ключ сравнения включает букву, ID задания, версию геометрии, версию оценки, размер, толщину, допуск, просвет и фактический тип подсказки. Разные переносы текста имеют разные ID. Профиль использует фактические значения размера/bold/допуска/просвета, включая техническое переопределение. Старые результаты при ослабленных подсказках сохраняются под прежним профилем.

Журнал показывает последнюю и лучшую сопоставимые попытки и до трёх последних результатов. Кнопка повторения ведёт к заданию с меньшим последним процентом. Она сохраняет его работу; повторное начало доступно через процент и сброс. При другом переносе строки переход ищет то же задание по названию. История не объявляет букву освоенной.

Оба журнала перечитывают данные перед сохранением и объединяют изменения вкладок. Чернила сохраняются по трёхстороннему сравнению текущего поля, его исходного снимка и последней записи. Undo затрагивает только свои поля. Одинаковое поле в двух одновременно пишущих вкладках использует последнее изменение; это локальный лист одного ученика, не совместный редактор.

## Резервная копия

В настройках можно скачать JSON и выбрать его для восстановления. Файл остаётся локальным: сервер не принимает загрузки. Экспорт включает ожидающие записи рисунков и журналов из памяти после ошибки сохранения. Повреждённые старые записи помещаются в отдельный архив файла, не блокируя восстановление корректных записей.

Импорт проверяет формат, версии, известные ключи и координаты. Он добавляет отсутствующие/пустые пробы, объединяет журналы и сохраняет существующие непустые рисунки при конфликте. Существующие настройки имеют приоритет. Ошибка места откатывает записи импорта; если браузер отказывает и в откате, показывается отдельное сообщение и остаётся исходный файл копии. Архив повреждённых записей автоматически не загружается обратно.

Автономный кеш ресурсов отделён от чернил в localStorage. Обновление приложения не сбрасывает данные. Смена origin или браузера создаёт другое хранилище; для переноса нужен файл. Автоматическую вечную сохранность браузерного хранилища не обещаем.

## Palm guard — сборка 32

WorksheetInput подключён до runtime и получает stylusOnly из applyInputControls. Он отслеживает активные pen ID, touch ID, отклонённые контакты и 800мс после последнего события пера. Защита от click (1000мс после отклонённого touch) включает старый WebKit без pointerType; разовый legacy-click после pen/mouse release разрешён, если палец не вмешался. Состояние не сохраняется. Callback setTouchCancellation отменяет только незавершённый touch, а при скрытии документа — любой незавершённый штрих.

Причина изменения подхода: прежние unit-тесты проверяли рисунок от touch только на canvas и не проверяли document capture → нативные действия/кнопки → разрыв между штрихами. Новый canary проходит весь этот путь и возврат управления; интеграция использует настоящий setupSurface. Отдельная браузерная проба посылает синтетические PointerEvents реальным кнопкам и проверяет computed touch-action; это не аппаратная проверка Apple Pencil.

Обоснование границы: W3C Pointer Events (https://www.w3.org/TR/pointerevents2/) разделяет нативный pan и default-action PointerEvent; отмена pointerdown сама по себе не запрещает viewport pan. Поэтому одновременно применяются touch-action и non-passive Touch Events. WebKit Safari18.2 (https://webkit.org/blog/16301/webkit-features-in-safari-18-2/) документирует pointerType в click; для прежних версий оставлен compatibility fallback.

## Отменяемая подсветка — сборка39

FeedbackJobs подключён после TraceFeedback. Сервис лениво создаёт один feedback-worker.js; prefetch в HTML включает entry point в локальную offline-сборку. Запрос ставится в очередь через отдельную задачу. Идентификатор активного задания проверяется на ответе; отменённые queued jobs удаляются до dispatch, in-flight ответы игнорируются. Смена поля/закрытие сброса/очистка/destroy отменяют потребителей; generation и ключ исходных чернил/draft/допуска дополнительно защищают DOM от позднего ответа.

Worker выполняет TraceFeedback.steps; при отсутствии/ошибке Worker тот же generator работает порциями до32yield или4мс, yield внутри сканирования через256сегментов. Нормализация и sampling линейны; эти пределы не являются универсальной гарантией времени для неограниченного входа. Сервис локален, без сети статистики. Формула процента не менялась.

Клик процента показывает уже привязанный сброс немедленно и заказывает missing/extra. Paint увеличенной копии только читает кеш и заказывает outside, не анализирует геометрию. Пустые пробы не заказывают feedback. Late reply не может вернуть красные линии после reset или поверх новой буквы. Reset/undo вызывают refresh только затронутых ID; LearnerExperience.work исключает видимые самостоятельные пробы до вычисления сохранённых. Per-field snapshot не копирует весь лист; clear-all сохраняет прежний полный снимок.

Регрессии находятся в ink-storage.test.cjs (быстрый критический сценарий), worksheet-dock.test.cjs и tests/helpers/feedback-jobs.cjs (worker/fallback/cancel/late reply/совпадение геометрии). Браузерная проверка десктопным указателем не подтверждает физический Pencil.

## Tap actions — сборка42

## Статистика и время — сборка45

`WritingTimes` подключён перед runtime (и в editor). Канонические одиночные пробы — `gost-file-b90-upper/lower-N`; разминка/словесные блоки/independent не создают таймерных записей.
