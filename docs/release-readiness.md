# Готовность к выпуску Букв по ГОСТ

Сборка 26 — законченный кандидат веб-версии для внутренней проверки. Подготовлены автономный комплект, сохранение и перенос работ, учебные подсказки и журнал. Публичный выпуск и отправка в App Store требуют закрытия перечисленных ниже условий владельцем.

## Поставка без Xcode

Для текущей проверки выбран самостоятельный PWA-комплект `dist/web/`. Все 33 урока, 40 рисунков каталога, ассоциации слов, контуры и оценка включены локально. Запросов к CDN, аналитике и сторонним API приложение не делает. Установка кеша проверяет SHA-256 каждого из 59 ресурсов. Обновление не активируется посреди письма: ожидающая версия применяется из настроек либо после закрытия старых вкладок. Кеш ресурсов и рисунки имеют отдельное хранение.

На localhost пройден полный путь: установка → письмо → журнал → обновление → остановка тестового сервера → новое открытие → все 33 урока → экспорт/восстановление → ещё одно открытие. Проверка браузера на Mac подтверждает этот комплект, но не установку на физическом iPad.

Для iPad PWA требуется предоставленный владельцем HTTPS-адрес. HTTP LAN-превью продолжает работать с включённым Mac; его не представляем установленным автономным приложением. Источник: [service workers и защищённый контекст](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation), [установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

Для будущего App Store предусмотрена отдельная оболочка iPadOS с вложенными локальными ресурсами и сохранением этой геометрии/данных. Открытие удалённого сайта не является выбранной архитектурой. Xcode не использовался, подписанный бинарный файл не создавался, облачная сборка/сертификаты не настроены. PWA-архив не является файлом для загрузки в App Store. Перед выбором конкретного сборочного сервиса нужны аккаунт владельца, идентификатор приложения, модель подписи и разрешённый процесс сборки.

## Права на ресурсы

| Ресурс | Что установлено | Условие распространения |
|---|---|---|
| ASCON GOST type B Regular | TTF из архива iSopromat, SHA-256 и copyright в SOURCE.json; контуры извлечены из него | Письменное разрешение/лицензия на использование и распространение этих контуров в приложении, включая SVG-производные. В доступных материалах такого разрешения не найдено |
| 40 рисунков и 32 SVG ассоциаций | Геометрия и генераторы хранятся в репозитории; внешних изображений и загрузок внутри SVG нет | Подтвердить принадлежность проекту исходной геометрии при оформлении прав владельца |
| PNG арбуза | Существующий согласованный файл, происхождение/лицензия рядом с ним не зафиксированы | Владелец подтверждает источник и права либо отдельно согласует замену |
| Значок | Новый исходный SVG проекта, PNG 180/192/512 воспроизводятся сборщиком | Включён как ресурс проекта; финальную магазинную иконку проверить после выбора упаковки |
| Пропись 2019 | В поставку не включена; использован порядок букв, задания адаптированы отдельно | Не приписывать авторские задания исходному учебнику и не включать его сканы в приложение |

[Официальная документация ASCON](https://help.ascon.ru/KOMPAS/25/ru-RU/1054_126_4_ustanovka_shriftov.html) подтверждает поставку GOST type B с КОМПАС, но не предоставляет здесь лицензию на стороннее распространение. Бесплатная загрузка и технический флаг fsType=0 не заменяют разрешения. Текущую форму шрифта не подменяем другой ради обхода вопроса.

Для запроса владельцем прав нужны: наименование GOST type B, copyright 1996–2008 ASCON, хеш исходника, коммерческое/некоммерческое использование по фактической модели продукта, встраивание производных SVG-контуров, iPadOS/App Store и веб-демоверсия, территории, срок, условия указания авторства и обновлений. Запрос никому не отправлялся.

## Приватность текущей версии

Один локальный лист/журнал на браузерное хранилище, без регистрации и имён. Рисунки, проценты, попытки, выбранная буква и настройки остаются на устройстве. Рекламы, покупок, камеры, микрофона, контактов и телеметрии нет. Файл копии содержит работы и историю; место его сохранения выбирает владелец устройства. Удаление данных сайта средствами браузера удаляет местные работы; заранее сохранённый файл позволяет восстановить их.

Первое получение и обновление веб-комплекта обращаются к выбранному хостингу. Политику его технических журналов необходимо учесть после выбора хостинга. Для будущего подписанного приложения декларация App Privacy заполняется по фактическому бинарному составу и SDK, а не автоматически переносится из прототипа.

## Магазинные сведения

Рабочий заголовок: **Буквы по ГОСТ**. Подзаголовок: **Чертёжный шрифт на iPad**. Основная категория для рассмотрения — Education. Аудитория продукта остаётся 7–11 лет; возрастной рейтинг магазина и возрастная полоса Kids — отдельные поля. Apple предлагает полосы 5 и младше, 6–8, 9–11; выбрать одну по результатам проверки основной аудитории, не выдумывая полосу 7–11. [Требования Apple к Kids](https://developer.apple.com/kids/).

Черновик описания:

> Тренируйте русский чертёжный шрифт ГОСТ типа Б без наклона. Посмотрите движение карандаша, попробуйте части буквы, заглавную и строчную формы, затем сочетания и короткие тексты. Контур помогает начать, а самостоятельная проба позволяет потренироваться без него. Локальные подсказки отмечают пропуски и линии вне допуска; журнал показывает ваши попытки. Стилус поддерживается, рисунки и история сохраняются на устройстве.

В окончательное описание добавить работу без сети только после испытания установленного iPad-приложения. Не заявлять сертификацию ГОСТ, педагогическую эффективность, гарантированное освоение или аппаратное распознавание ладони.

Для страницы магазина подготовить настоящие снимки: лист А с обоими регистрами; локальная подсказка; осмысленный текст среднего урока; самостоятельная проба; журнал. Технические снимки браузера в отчёте не являются магазинными снимками iPad.

Support URL, Privacy Policy URL, имя/контакты издателя, территории, цена и возрастная анкета остаются данными владельца. Пустые значения не заменены вымышленными. Черновик для App Review: вход не нужен; в настройках можно разрешить палец для проверки без Pencil; процент открывает сброс и локальную подсказку; 100% не требуется для завершения; записи локальные. Окончательные заметки обновить по подписанной версии.
