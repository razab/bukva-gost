# Внутренняя поставка

Из корня проекта, Node>=20, Python3 и установленные dev-зависимости (`npm ci`):

```sh
npm run package:internal
```

Команда пересобирает `dist/web/`, проверяет whitelist, SHA-256 всех ресурсов,
соответствие версии manifest и зависимости HTML, затем создаёт:

```text
dist/internal/<build>/<bundle-version>/
  bukvy-po-gost-<build>-internal.zip
  bukvy-po-gost-<build>-internal.zip.sha256
  package.json
  RESOURCE-NOTICES.json
```

ZIP содержит только `web/`, `README-INTERNAL.txt` и `RESOURCE-NOTICES.json`.
Опись даёт размер, SHA-256 и происхождение каждого файла. Исходный TTF, PDF,
редактор, тесты и инструкции разработки не включаются. ASCON-производные контуры
в `glyphs.js` отмечены отдельно; отсутствие TTF не снимает вопрос их лицензии.
Для PNG арбуза источник неизвестен. Для авторских материалов проекта требуется
подтверждение принадлежности владельцем.

До появления готового каталога ZIP проверяется через чтение каждого его файла
и CRC. Фиксированы порядок, timestamp и права записей; повторный запуск с теми же
байтами в той же среде Python/zlib даёт тот же ZIP. Совпадение между разными
версиями компрессора не обещается. Уже существующий иной результат оставляется
нетронутым; команда завершается ошибкой. Старые ручные архивы не удаляются.
После прерывания могут остаться только скрытые `.package-*` каталоги подготовки;
повторная команда создаёт новый и не принимает их за готовый результат.

Это комплект **INTERNAL REVIEW ONLY**, без публикации, аккаунтов, подписи и
загрузки на внешние сервисы. Запуск напрямую через `file://` не является
проверенной установкой. Для автономной PWA на iPad нужен HTTPS; LAN-превью
продолжает зависеть от работающего Mac. Физическая приёмка — [отдельно](ipad-pilot.md).
