## Решение
Отдельная страница editor/letter-atlas.html подключает исходные glyphs.js/writing-scheme.js обычными script. Без зависимостей, iframe уроков и localStorage. Контур использует тот же font transform и формулу bold, что runtime; стрелки — общий WritingScheme.markup. Одна рамка пары сохраняет относительный масштаб регистров. Никакой автоподгонки каждой буквы до одинаковой высоты.

Встроенный браузер запретил file URL. Доступ к файловой системе браузеру не выдаётся: отдельный read-only HTTP-сервис на 127.0.0.1:8782 публикует явный allowlist четырёх ресурсов. Никаких directory serving, доступа к проектному root или изменений LAN8781. Сервис зарегистрирован и запущен через Local Projects API; readiness подтверждает отдельную identity. Подмена Host проверяется node:http, поскольку fetch в canary нормализовал Host и дал ошибочное ожидание теста; исправленный минимальный тест прошёл и сохранён в learner-server.test.mjs.

Canary: две пары А/Е, реальное открытие, совпадение markup, масштаб, bold, reload. После него полный алфавит. Контролы select (предопределённые размеры/толщины) и поиск; непрерывные анимации 66 букв не запускаются. Стенд проверяет статические схемы; анимационные и аппаратные проверки остаются отдельными.

Ponytail установлен официальным Codex plugin CLI. Авторизация lifecycle hooks отделена от установки: не редактировать trust-store вручную. В этой задаче правила прочитаны явно.
