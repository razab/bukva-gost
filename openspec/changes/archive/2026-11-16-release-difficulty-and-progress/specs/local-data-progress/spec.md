## MODIFIED Requirements

### Requirement: Сводка по завершённой практике
Сводка MUST показывать название сложности сохранённого занятия, средний процент одиночных заглавных/строчных и общий процент заполненной практики по контуру, исключая independent и рисунок. Фактический допуск SHALL сохраняться в записи.

#### Scenario: Сводка по завершённой практике
- **WHEN** сохранено занятие с разными типами полей
- **THEN** группы и общий процент имеют корректный состав без примеси самостоятельной дорисовки
- **AND** показанная сложность относится к условиям этого занятия

#### Scenario: Результат по букве
- **WHEN** пользователь смотрит сохранённый результат по контуру в «Буквах» или «Прогрессе»
- **THEN** рядом с процентом видна сложность того же занятия без наведения
- **AND** смена текущей сложности не изменяет закрытое занятие и его подпись

#### Scenario: Старая запись без допуска
- **WHEN** у сохранённого результата отсутствует допуск
- **THEN** процент остаётся доступным с пометкой «Сложность не записана»
