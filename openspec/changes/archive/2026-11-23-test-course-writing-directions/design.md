## Decisions

- Один изолированный стенд использует реальные поля каждого урока. У каждого
  типа элемента проверяется одно поле, повторения используют тот же компонент.
- Образцы обеих форм читаются из SVG, текст получает смещения букв из своего
  SVG. Для разминок используется сопоставление с учебными штрихами и проверка
  стрелок. Для допущенных способов движения сохраняются отдельные проверки.
- Для уверенного обратного движения разворачивается только один различимый
  штрих. Тест различает начало правильного штриха, короткую поправку и
  намеренное обратное движение. Проверяются процент, отметка и сброс.
- Полный набор запускает сценарий автоматически. Негативные контроли проверяют,
  что тест ловит расхождение, и восстанавливают подменённое поведение.
- Проверка в WebKit приложения проходит те же уроки и смонтированные разминки
  на симуляторе iPad. Тест использует отдельное временное хранилище.
- Для отрицательного сценария обратный штрих проводится первым. При проверке
  последним он иногда продолжал разрешённое соединение двух траекторий и
  получался другой допустимый жест. Порядок нужен для однозначного входа.
