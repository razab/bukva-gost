## Результаты

- Контроль обнаруживает оба намеренных сбоя: единственный обратный штрих в
  оценщике при верном образце и потерю отметки об обратном направлении.
- В Node пройдены 33 урока. По 66 форм и 66 самостоятельных проб на уровнях
  «Обычно» и «Точнее», 160 текстовых строк на уровне «Обычно», из них 27 с
  переносом. Для текста в каждом поле проверен один различимый штрих, рядом с
  которым уже нанесены остальные штрихи.
- На симуляторе iPad Pro 11″ в WebKit установленного пакета пройдено 66 форм,
  120 смонтированных разминок и 314 случаев с одним обратным штрихом. Ввод
  синтетический. Физический Apple Pencil в этой проверке не использовался.
- В изолированной копии восстановили прежний выбор направления для разминки
  при сохранённых новых стрелках. Общий тест отклонил результат
  `backward` для штриха по стрелке в `gost-b90-42b-part-0`.
- Полный набор прошёл 35/35 файлов. Порог покрытия пройден для полного и
  среднего набора.
