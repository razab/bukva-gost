# Proposal

## Why

Проверки курса и внутреннего ZIP не проверяют риски App Store Review. Нужен повторяемый запуск, который объединяет технические факты и анализ по Apple Guidelines, различает доказанные проблемы и непроверенные условия, не выдавая веб-прототип за проверенную iPad-сборку.

## What Changes

- Один основной вызов в Codex: `$apple-preflight`. Проектный skill запускает локальную проверку и выполняет содержательный аудит по `safaiyeh/app-store-review-skill`, затем оставляет общий Markdown/JSON-отчёт.
- Локальная команда `npm run check:apple` доступна отдельно: без AI и сетевых запросов проверяет доступные технические артефакты и создаёт машиночитаемый отчёт. Она не подменяет содержательный аудит.
- Повторно использовать проверку whitelist/хешей автономного комплекта, дополнить сверкой с текущим исходником. Отмечать включённые dev-ресурсы, незаполненные сведения о правах и отсутствие нативного артефакта.
- В содержательный аудит входят Kids/родительские барьеры, приватность, самостоятельная ценность, магазинные сведения, права и доступность функций проверяющему. Каждый вывод связан с доказательством и официальным пунктом Apple.
- Статусы: PASS конкретной проверки, BLOCK, FLAG, UNKNOWN, NOT_CHECKED, N/A. Проверки конкретного подписанного приложения, устройства и App Store Connect без соответствующих входных данных остаются явно непроведёнными.
- Зафиксировать версию внешнего skill; не обновлять/запускать внешние скрипты автоматически. От остальных найденных skills использовать только рассмотренные идеи формата отчёта, не устанавливать три пересекающихся пакета.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `verification`: повторяемая проверка рисков Apple Review с доказательствами, происхождением правил и честной границей автоматизации.

## Impact

Планируются проектные dev-skills, небольшой Node-скрипт, его тесты, команды package.json и документация проверки. Пользовательский runtime, номер сборки56, чернила и геометрия не меняются. Не входят установка Xcode/SDK, создание iPad-оболочки, полноценный парсер `.xcarchive`, доступ к App Store Connect, публикация, автоисправления и новые продуктовые функции.

Это предложение для просмотра. Установка skills, написание скрипта и аудит приложения начнутся после одобрения этих документов.
