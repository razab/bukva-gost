# Наблюдения при реализации

- Сначала проверялся функциональный API; добавленный реальный CLI-тест поймал тихий exit0 при запуске через symlink. Минимальное воспроизведение: argv содержал ссылочный путь, import.meta.url — канонический; основной обработчик не вызывался, stdout был пуст.
- Проверка остановлена до объявления PASS. Точка входа теперь сравнивает канонические пути; регрессия проверяет реальный процесс, его код и появление отчёта. Функциональный API остаётся отдельно проверенным. Старые runner/package вне текущего объёма не изменяются по аналогии без подтверждённого сценария.
- Системному Python для валидатора skills не хватало PyYAML. Валидатор запущен в отдельном временном venv с PyYAML6.0.3; глобальная Python-среда и runtime приложения не менялись.
- Canary: reports/apple-review/canary-2026-11-08/ и canary-fixtures-2026-11-08/. Позднейшие изменения движка делают их историческими; итоговый аудит создаётся заново.
- Проба приватных LAN-путей сначала ошибочно принимала только404. Установлено: сервер возвращает403 для dot-пути и404 для остальных отсутствующих ресурсов. Проверка допускает оба запрета; повторно подтверждены все три пути. Это исправление проверочного предположения, не дефект/правка сервера. Доказательство: reports/apple-review/deployment-2026-11-08.json.
