Baseline создан из поведения сборки 55, подтверждённых решений владельца,
исходников и проверок. Снимок прежнего AGENTS сохранён побайтно:
`docs/history/agent-rules-before-openspec.md`. Прежний README — рядом.
Их старые временные параметры не становятся новыми требованиями.

## Как разрешены временные противоречия

- Высота шапки 180/144 была заменена 140/128; baseline использует последнее решение.
- Длительный 800 мс guard и эвристика размера ладони были отменены; обычный
  независимый scroll после pen-up сохраняется.
- Порядок А вверх-вниз был заменён учебным источником сборки 50; отдельная старая
  демонстрация не возвращается автоматически из исторического текста.
- Запрет технического UI во фронте позднее получил явное исключение для
  закрытого дев-попапа LAN-прототипа; это не developer account.
- Последнее решение о Я/я из переписки: текущая цельная схема остаётся,
  предложенная staged-иллюстрация отвергнута.
- Отложенный timing не удалён: baseline описывает существующий сбор/показ,
  а дальнейшее развитие остаётся в PROJECT-PLAN.
- «Три зелёных результата», «новая попытка» и переходы не объявлены внедрёнными
  из одного факта наличия reset/журнала. Они явно разобраны в анализе.

Ни у одной прошлой сборки не создан вымышленный change. Десять продуктовых specs —
исходный снимок требований; единственный первый архив — реальное внедрение OpenSpec.
