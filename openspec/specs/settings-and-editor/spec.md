# Общие настройки и авторский состав

## Purpose

Разделить общие параметры практики и состав конкретного урока, сохраняя доступный владельцу прототипный редактор и отзывчивые регуляторы.

## Requirements

### Requirement: Общие параметры уроков
Размер, bold, допуск, интервалы, левый отступ и косметика пера SHALL сохраняться общими для всех букв.

#### Scenario: Общие параметры уроков
- **WHEN** пользователь меняет параметр и открывает другую букву
- **THEN** она использует тот же параметр, а сохранённые пробы остаются доступными.

### Requirement: Базовый профиль
Новый пользовательский профиль SHALL использовать размер 92,bold 100%,допуск 8 px,интервалы рядов/проб 16 px,просвет 20%,отступ 15%,перо 3 px,сглаживание 0.

#### Scenario: Базовый профиль
- **WHEN** нет сохранённых переопределений
- **THEN** параметры отображаются как фактически выбранные значения.

### Requirement: Пять уровней и ручной допуск
Уровни MUST задавать радиусы 12/8/4/2/1 CSS px; ручной допуск 0,5–16 с шагом 0,5 доступен в обычных настройках.

#### Scenario: Пять уровней и ручной допуск
- **WHEN** выбран preset или нестандартное ручное значение
- **THEN** видно выбранное число; нестандартное значение обозначается как свой допуск без скрытой зависимости от размера.

### Requirement: Предсказуемые шкалы
Числовые шкалы MUST быть монотонными, с отдельной отметкой дефолта, без подмены крайнего числа значением «авто».

#### Scenario: Предсказуемые шкалы
- **WHEN** межбуквенный интервал двигается влево до конца
- **THEN** получается 0%, а 20% остаётся отдельной отметкой по умолчанию.

### Requirement: Лёгкое preview и один commit
Частые input-события ползунка SHALL обновлять лёгкое preview; тяжёлое изменение и сохранение выполняются один раз на change/blur.

#### Scenario: Лёгкое preview и один commit
- **WHEN** допуск перетаскивается длинной серией input
- **THEN** нет многократной пересборки, оценки и записи; commit сохраняет DOM/undo/чернила, кроме необходимого изменения переноса.

### Requirement: Полный контракт регуляторов
Регуляторы MUST сохранять диапазоны: size 30–160,bold 100–150,rowGap 0–80,columnGap 0–60,letterGap 0–50,leftInset 0–30,penWidth 0,5–8,smoothing 0–2 и отдельный допуск.

#### Scenario: Полный контракт регуляторов
- **WHEN** параметр меняется на минимум, середину и максимум
- **THEN** интерфейс, эффект, шаг, сохранение и reload соответствуют явному тестовому контракту.

### Requirement: Отдельный технический интерфейс
Технический popup SHALL быть закрыт по умолчанию; во Wi-Fi-прототипе вход доступен через настройки, но не является защищённым dev-аккаунтом.

#### Scenario: Отдельный технический интерфейс
- **WHEN** автор открывает «Для разработки»
- **THEN** доступны оформления и состав; приложение не объявляет этот dialog механизмом авторизации.

### Requirement: Сохранность авторского состава
Редактирование состава SHALL действовать на текущую страницу, сохраняя явные ручные строки, исключения частей и прежние черновики при миграциях.

#### Scenario: Сохранность авторского состава
- **WHEN** обновляется стандартная программа курса
- **THEN** автоматически заменяется только точно распознанный прежний стандартный состав с архивом исходника.
