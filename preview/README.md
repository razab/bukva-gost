# Буква А: браузерный прототип

Откройте index.html в браузере. Все материалы находятся в одном файле, сеть не требуется. Рисунок сохраняется в хранилище браузера, если оно доступно. Для просмотра на iPad перенесите файл на устройство и откройте в браузере; поведение локального хранилища зависит от способа открытия. Это прототип, не готовое приложение App Store. Проверки на настоящем iPad и Apple Pencil ещё не проводились.
