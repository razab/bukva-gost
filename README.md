# Буквы по ГОСТ

Планшетный тренажёр русского чертёжного письма для детей 7–11 лет.
ГОСТ 2.304-81, тип Б без наклона;33 урока, оба регистра, динамический пример,
собственные части букв, слова/тексты, самостоятельная проба и дорисовка.
Начинать можно без навыка письма.

## Три уровня проверок

Установить только инструменты тестирования: `npm ci`. Приложению на iPad эти зависимости не нужны.

| Запуск | Команда | Состав | Когда запускать |
|---|---|---|---|
| Быстрый | `npm test` | 3 из 32 файлов, 9,4%; все ползунки, сохранность чернил, ввод/ладонь | После обычной правки |
| Средний | `npm run test:medium` | 9 из 32, 28,1%; включает быстрый и основные сценарии листа, урока, допуска, закреплённой шапки и offline | Перед передачей изменений |
| Полный | `npm run test:full` | Все 32; включает растровые регрессии 66 форм,40 рисунков, иконки, порядок, журнал, сервер и сам тестовый запуск | Перед выпуском и после общих изменений движка |

Считаются тестовые **файлы**, каждый содержит несколько сценариев. Средний автоматически ограничен 30% набора; быстрый держится около 10% (8–11% с округлением). Точный текущий список — `npm run test:list` и scripts/test-catalog.mjs. Новые `*.test.cjs`/`*.test.mjs` автоматически попадают в полный набор.

Средний и полный должны выполнить минимум 70% **строк, функций и ветвлений** браузерного JS (concepts/components/*.js и service worker). Покрытие измеряет c8/V8, включая VM-скрипты с их настоящими именами. Источники не исключаются ради нужной цифры. Тестовый DOM, зависимости и Node-сервер не входят в этот процент; сервер имеет отдельную HTTP-проверку. Покрытие исполнения не доказывает правильность всех сценариев — для этого нужны сами утверждения тестов. Сжатые файлы дают высокий процент строк, поэтому смотреть также на функции и ветвления.

Полный запуск вычисляет отчёты quick/medium из тех же выполнений, без повторного запуска тестов, и проверяет порог среднего отдельно. Зависимости и серверная раздача не используются для имитации физического iPad: жесты Safari, Apple Pencil и ладонь остаются отдельной проверкой на устройстве.

### Проверка каждого ползунка

sliders.test.cjs автоматически сверяет ползунки обеих страниц с девятью явными контрактами: размер букв, bold, допуск, расстояние между рядами, между пробами, между буквами, отступ слева, толщина пера, плавность. Новый ползунок без контракта делает тест красным. Проверяются реальные oninput/change/blur, минимум/середина/максимум/шаг, наблюдаемый эффект, вывод значения, сохранение и reload, плохие значения, запрет изменения во время штриха, сохранность чернил и undo.

Отдельные регрессии tolerance-performance.test.cjs и pen-часть sliders.test.cjs проверяют серии input без лишних сохранений/пересборок, один commit и отсутствие влияния косметики на оценку.

### Отчёты и продолжение

Каждый запуск создаёт отдельный reports/test-runs/<дата>-<уровень>-<pid> с summary.json/txt, coverage/coverage-summary.json, логом каждого теста и state.json. Результат каждого файла записывается сразу, тесты идут последовательно, у каждого есть таймаут. Прерванный или упавший тест не считается пройденным.

Продолжить: `node scripts/test.mjs --resume <каталог-отчёта>`. Успешные проверки повторно не исполняются; упавшие/прерванные выполняются заново. Изменение исходников, тестов или lock-файла запрещает повторное использование старых PASS: нужен новый отчёт. Полный/средний перед проверкой собирают свежую offline-версию, чтобы не проверять устаревший dist. Скрытые переменные canary-only не могут сократить именованный набор.

Проверка самого запуска: test-runner.test.mjs — успешный/упавший дочерний процесс, сохранённые логи, resume без повторения PASS, отказ при изменении источника, таймаут и прерывание.

Исторический полный замер (05.11.2026, сборка 45): quick7.40 с, medium34.20 с, full176.38 с. Все 32 файла прошли; medium/full gates пройдены. Полный: 100% строк, 90.88% функций, 89.53% ветвей. Отчёт reports/test-runs/2026-11-05T20-00-29-427Z-full-48427/summary.json. Сводка проверена в 3 размерах; native mouse→reload→finish подтвердил сохранение времени на А и ы.
